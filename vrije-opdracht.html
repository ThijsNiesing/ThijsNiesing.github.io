4.2 Wat is shiny

Met shiny kan je verschillende data omzetten naar interactieve apps binnen r. Als je zo een app hebt gemaakt kan je op parameters drukken en zo de data analyseren en visualiseren. Er zijn allemaal verschillende applicaties. Een voorbeeld hiervan zijn bijvoorbeeld het kunnen maken van een overzicht van hoe alle bussen in een land rijden. Binnen deze app kan je dan selecteren welke route je wilt bekijken en hier meer informatie van zien.

4.3 Hoe werkt shiny

Om shiny te kunnen gebruiken moeten er altijd een app.r bestand zijn. Je hebt hierin een ui bestand nodig. Dit staat voor user interface. Dit zorgt voor hoe je app eruit komt te zien. Ook heb je een server bestand nodig. Het server bestand zorgt ervoor dat de app gerund kan worden. Om dan de app te kunnen runnen moet de runApp command gebruikt worden. ## Werken met shiny ### De scripts Hieronder zijn de gemaakte en gebruikte scripts te zien voor de shiny. De eerste chunck laat de server en de ui code’s zien van de interactieve tabel.

# Server
# Laat de datasets library om toegang te krijgen tot de penguins data
library(datasets)

function(input, output) {
  
  # Zorg ervoor dat de gefilteerde data aan te klikken is in de tabel en verwijder NA
  output$table <- DT::renderDataTable(DT::datatable({
    data <- na.omit(penguins)
    # Standaard input is alle soorten. Vervolgens kan er een soort gekozen worden
    if (input$species != "All") {
      data <- data[data$species == input$species,]
    }
    if (input$sex != "All") {
      data <- data[data$sex == input$sex,]
    }
    if (input$year != "All") {
      data <- data[data$year == input$year,]
    }
    data
  }))
  
}

Hieronder staan de codes van de server en UI bestanden voor de cluster groepering.

# Server
function(input, output, session) {
  
  # Zorg ervoor dat de variabele in de data komen. Verwijder ook de NA.
  selectedData <- reactive({
    na.omit(penguins[, c(input$xcol, input$ycol)])
  })
  
  # Formule voor het maken van de clusters
  clusters <- reactive({
    kmeans(selectedData(), input$clusters)
  })
  
  # Het geven van de kleuren aan de verschillende clusters
  output$plot1 <- renderPlot({
    palette(c("yellow", "red", "pink", "blue",
              "orange", "green", "brown", "purple", "grey"))
    
    # Het geven van symbolen aan de species
    species_pch <- c(
      Adelie = 16,      # rond
      Gentoo = 17,      # driehoek
      Chinstrap = 15    # vierkant
    )
    # Selecteer de juiste afmetingen en variabelen voor in het figuur.
    par(mar = c(5.1, 4.1, 0, 1))
    plot(selectedData(),
         col = clusters()$cluster,
         pch = species_pch[na.omit(penguins)$species],
        cex = 2.5,
        xlab = input$xcol,
        ylab = input$ycol)
    # Het maken van de kruisjes waar de clusters worden aangegeven
    points(clusters()$centers, pch = 4, cex = 4, lwd = 3)
    
    # Legenda voor in het figuur
    legend(
      "topright",
      legend = names(species_pch),
      pch = species_pch,
      title = "Species")
  })
  
}
